# Aether LLM Skill Pack

This folder packages Aether as an agent-facing skill: concise instructions,
decision rules, examples, and command recipes that help coding agents use
Aether as a framework instead of rewriting source files directly.

The intended users are agent tools such as Codex, Claude Code, OpenRouter
wrappers, Gemini/Ollama coding loops, and self-healing systems.

## What The Skill Teaches

- choose raw generation for tiny throwaway code;
- choose Aether state transitions for focused edits, medium/large files, or
  safety-sensitive changes;
- emit valid Aether patch JSON;
- validate before apply;
- prefer `PatchOrchestrator` for snapshot-backed apply/rollback;
- report structured errors instead of silently rewriting files.

## Quick Agent Contract

Agents should produce either:

1. a normal code answer, when the task is a tiny draft or explanation; or
2. an Aether patch JSON object, when modifying an existing codebase.

For Aether mode, the patch must follow:

```text
sdk/python/ai_runtime/validation/patch_schema.json
```

Then the host should run:

```bash
ae-safe status --project .
```

or call:

```python
from ai_runtime import PatchOrchestrator

result = PatchOrchestrator(project_root=".").apply(patch)
```

## Files

- `SKILL.md` - core instructions an LLM agent should read.
- `decision_policy.md` - when to use raw generation, state mode, full Aether,
  or hybrid routing.
- `examples/modify_function_patch.json` - minimal valid patch.
- `examples/run_script_patch.json` - sandboxed script example.
- `examples/healing_agent_verify_config.py` - Healing Agent verify-gate setup.
- `model_prompt.md` - short prompt block for agent wrappers.

## Built Module

The benchmark builds a transaction-risk scoring module from scratch:

- typed transaction and score data models;
- robust median/MAD amount outlier logic;
- account velocity features;
- country, time-of-day, device-age, and category-risk signals;
- calibrated logistic-style review probability;
- JSON model serialization;
- CLI training/evaluation command;
- unit test quality gates.

## Build Modes

- `raw`: full package source emitted directly.
- `aether`: compact state transitions compiled into package source.

## Limitations

- This is a deterministic local project build benchmark, not a live LLM generation study.
- The Aether path uses compact state transitions compiled into code, so it measures architecture leverage rather than prompt-only behavior.
- Token counts use a local code-token estimate, not provider billing tokens.
- The final generated project size is intentionally equal in both modes; savings measure what the agent would need to write, not the final source size.
